## 内容保护与已知限制

- 语音转写、通话摘要、AI 进度正文、用户提交的侧问以及 SSH 远端提示正文保留原文。相应的界面控件可以翻译。
- 首次使用页的条款和勾选项说明已翻译，链接、按钮和勾选行为予以保留。
- 编辑器正文、第三方网页、Google 内部界面、协调器欢迎语的逐词动画及未匹配的混排句子保留原文。Monaco 和 VS Code 的颜色说明、编辑器和布局库的部分消息，以及 KaTeX 帮助也保留原文。
