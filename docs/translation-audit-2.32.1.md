## 引擎适配

- WSL 菜单在主菜单本地化之后异步插入；现已让菜单查找同时识别原文和译文，并在每次安装菜单前翻译新增项目。
- 若归档包含 IDE 向导和 SSH 独立 preload，则为它们注入引擎；旧归档没有这些文件时继续使用原有流程。
- 新增保护 AI 进度正文、语音摘要正文和侧问标题中的用户原文。SSH 远端传来的任意提示正文及输入值保留原文。
- 常规设置的权限说明由完整句子、空格和独立帮助链接组成。允许这一结构中的完整文案与链接分别翻译，保留链接结构；未知句子中的内联链接继续受片段保护。
- 已知且各自完整的相邻句子可独立翻译，保留加粗节点。提示框中将严格的快捷键标签与界面标签分开处理，快捷键本身不变。用户和 AI 内容区域中的动态 `title`、`alt` 等属性也保持原文；编辑器自身的界面标签仍可翻译。
- 25 条 `inlineMessages` 为明确的界面组件登记完整源句和节点占位符，覆盖条款、浏览器 Chrome 要求、模型文档、法律帮助、麦克风入口、项目权限的 12 个变体、插件登录、云资源浏览、IDE 向导及首次使用条款页。引擎只修改原文本节点的值，不插入、删除或移动节点，原链接、按钮、事件和任意名称保留。模板及占位符顺序会在写入归档前校验。
- 首次使用条款页的两段说明由产品名和正文分别渲染；数据收集勾选项还包含加粗标题、服务条款和隐私政策链接。四条专用规则翻译这些完整组件，保留品牌文本节点、加粗样式、链接和勾选行为，不修改选项状态。
- 两条新增动态规则翻译插件账号的云端登录与本机凭据说明，包括提供方列表，以及凭据仅发送到指定域名的约束。

IDE 向导中含加粗品牌名 `Antigravity IDE` 的说明长段落已能完整翻译，原加粗节点保留。协调器欢迎正文的逐词动画，以及未登记的复杂混排仍保留原文；本次没有重建动画或全局展平 DOM。内部界面、编辑器正文、第三方网页和未识别的完整句子不在本次翻译覆盖声明中。

## 复查方法

启动 Antigravity 后，用 PowerShell 7 在项目目录执行：

```powershell
.\scripts\audit-ui.ps1
```

脚本只读取安装信息、静态界面资源，以及布局和公开入门预设这两类已确认的运行时文案。支持本地 HTTP、HTTPS 服务，输出候选、源码上下文、公开文案和 bundle 哈希到临时目录；不修改客户端，不保存包含会话凭据的启动 HTML 或原始接口响应。也可只扫描已保存的静态 bundle：

```powershell
.\scripts\audit-ui.ps1 -BundlePath 'C:\path\to\main.js'
```

输出是供人工审核的候选，包含第三方库和内部字段等噪声，也未扣除动态规则已覆盖的文本。运行模式额外检查已确认的两个公开文案来源，共 30 项；其他运行时文案仍需结合实际页面检查。仅提供静态 bundle 时不读取运行时配置。候选数量不能当成缺失翻译数量或覆盖率。
